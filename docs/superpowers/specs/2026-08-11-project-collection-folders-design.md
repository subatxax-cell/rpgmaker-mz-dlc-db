# 项目收藏夹与无限层级目录设计

## 目标

在现有 RPG Maker MZ DLC 数据库中增加个人“项目收藏夹”。用户可以建立多个游戏项目，在项目内创建无限层级目录，并将任意 DLC 同时归类到多个项目或目录。新增功能必须与现有 DLC 浏览、搜索、筛选、排序、媒体预览和个人标记完整兼容。

## 已确认的产品规则

- 左侧菜单新增“项目收藏夹”区域和固定的“新建项目”按钮。
- 项目是目录树的根节点，项目下面可以无限嵌套子目录。
- 所有 DLC 均可加入项目收藏夹，不要求先标记“想买”或“已拥有”。
- 同一 DLC 可以同时属于多个项目和多个目录。
- DLC 可以直接归类到项目根节点，也可以归类到任意深度的子目录。
- 项目和目录支持拖拽排序，也支持拖拽改变父目录。
- 删除项目或目录只删除目录节点及相关归类关系，不影响 DLC、“已拥有”“想买”、个人评分或备注。
- 桌面采用左侧项目树；DLC 详情页提供多目录勾选；列表支持批量归类。
- 手机端提供“移动到……”菜单作为拖拽的完整替代操作。

## 数据模型

### 存储边界

个人数据拆分为三个相互独立的部分：

1. 现有个人标记：`owned`、`wanted`、`rating`、`notes`。
2. 项目目录树：项目、文件夹、父子关系和手动排序。
3. DLC 归类关系：稳定 Steam App ID 与多个目录节点 ID 的多对多关系。

项目收藏夹与现有个人标记存入同一份本地个人数据，但删除或修改其中一部分不得隐式修改另一部分。

### 版本化结构

```js
{
  version: 2,
  personalData: {
    "dlc-display-id": {
      owned: false,
      wanted: true,
      rating: 0,
      notes: ""
    }
  },
  projectCollections: {
    nodes: {
      "node-uuid": {
        id: "node-uuid",
        type: "project", // project | folder
        name: "勇者物语",
        parentId: null,
        order: 0,
        createdAt: "ISO-8601 timestamp",
        updatedAt: "ISO-8601 timestamp"
      }
    },
    assignments: {
      "steam-app-id": ["node-uuid", "another-node-uuid"]
    },
    expandedNodeIds: ["node-uuid"]
  }
}
```

- 项目节点的 `parentId` 必须为 `null`。
- 文件夹节点的父节点可以是项目或其他文件夹。
- 节点 ID 使用本地生成的稳定 UUID，不使用名称作为身份。
- DLC 归类使用 `steam_appid`，不使用可能变化的展示 ID 或标题。
- 每个 DLC 到同一节点最多保存一条关系。
- `order` 只在同一父节点的兄弟节点之间比较。
- 展开状态属于界面偏好；导出时保留，导入时可以恢复。

## 目录树约束

- 名称去除首尾空格后不能为空。
- 同一父节点下不允许同名节点；名称比较采用规范化后不区分大小写。
- 不同项目或不同父节点下允许重名。
- 项目不能移动到另一个项目或文件夹下面。
- 文件夹不能移动到自身或自己的任何后代中。
- 移动节点后重新生成目标兄弟列表的连续排序值。
- 删除节点时递归确定全部后代，在用户确认后一次删除节点集合和指向这些节点的归类关系。
- 删除操作不得删除 DLC，也不得修改个人标记。
- DLC 暂时下架或同步时未出现，归类关系仍保留；相同 App ID 恢复后自动重新显示。

## 左侧项目树

左侧菜单增加独立的“📁 项目收藏夹”区域：

- 区域顶部固定显示“＋ 新建项目”。
- 项目和有子节点的文件夹显示展开／收起箭头。
- 项目与文件夹显示名称和直接归类数量。
- 选中节点后高亮，并在主内容区显示该节点的 DLC。
- 项目和目录的 `⋯` 菜单提供：新建子目录、重命名、移动到、删除。
- 项目根节点不提供“移动到”。
- 二级及更深目录按深度缩进，但设置最大视觉缩进；更深层级仍以树线和图标表达层次，避免侧栏过窄。
- 支持键盘操作：聚焦、展开／折叠、选择节点和打开操作菜单。

### 拖拽

- 拖动节点上／下边缘调整同级顺序。
- 拖到文件夹或项目主体上改变父节点。
- 拖动期间显示目标位置和是否合法。
- 非法循环、把项目移入目录、同级重名等操作必须被拒绝并给出提示。
- 手机端和不适合拖拽的环境使用“移动到……”对话框完成相同操作。

## DLC 归类入口

### 详情页单个归类

详情弹窗新增“📁 加入项目目录”按钮。点击后打开目录选择器：

- 显示可展开、可搜索的完整项目树。
- 每个项目和目录都有复选框。
- 已包含当前 DLC 的节点自动勾选。
- 用户可以一次勾选多个节点并保存。
- 保存采用集合差异更新，取消勾选只移除对应归类关系。

### 列表批量归类

- 主列表提供“批量选择”模式。
- 卡片和表格行在该模式下显示复选框，点击卡片不再误开详情。
- 工具栏显示已选择数量、“加入项目目录”和“取消选择”。
- 目录选择器支持一次选择多个目标目录。
- 批量“加入”只增加关系，不移除每个 DLC 原有的其他目录关系。
- 退出批量模式后恢复现有卡片／表格点击行为。

## 浏览和过滤行为

- 点击项目或目录后，项目节点筛选与现有搜索、一级／二级分类、推荐度、价格、个人标记筛选组合使用。
- 排序仍在全部筛选完成后执行，默认保持“推荐度高优先”。
- 默认只显示直接归类到当前节点的 DLC。
- 提供“包含子目录”开关；开启后递归汇总全部后代中的 DLC。
- 同一 DLC 在子树内出现多次时只显示一次。
- 项目目录筛选与左侧官方 DLC 分类是两组独立条件；清除其中一组不得清除另一组。
- 目录被删除或当前节点不可用时，安全回到“全部 DLC”视图。

## 删除确认

删除前显示影响摘要：

- 将删除的项目／目录名称。
- 子目录数量。
- 将移除的唯一 DLC 归类关系数量。
- 明确说明 DLC 和个人标记不会被删除。

确认后执行单次事务式本地更新；验证或保存失败时保留原数据并显示错误。

## 本地保存、导入与导出

- 延续浏览器 `localStorage`，不向服务器上传个人项目数据。
- 采用单一版本化个人数据文档，或用兼容适配器从现有 `rpgmz-dlc-personal` 读取并迁移到版本 2。
- 首次加载旧数据时保留全部现有个人标记，并创建空项目收藏夹。
- 导出 JSON 包含版本、个人标记、项目树、归类关系和展开状态。
- 导入旧版文件时项目收藏夹默认为空。
- 导入新版文件前在内存中验证：版本、节点类型、父节点存在、无循环、兄弟名称唯一、排序值、归类目标存在、App ID 格式。
- 只有整份验证成功后才替换本地数据；失败时原数据保持不变。
- 导入后立即保存并重新渲染个人标记、项目树和当前列表。

## 现有功能兼容性

以下功能必须保持可用且行为不变：

- 官方 DLC 全量目录和 Steam 精确链接。
- 封面、介绍图片、视频和媒体轮播。
- 英文原文＋中文介绍。
- 搜索、价格区间、推荐度、官方分类和子分类。
- 推荐度高优先／低优先及其他排序。
- 卡片视图和表格视图。
- 已拥有、想买、个人评分和备注。
- 已拥有／想买／已评分个人筛选。
- 暗色模式。
- 导入与导出。
- 手机侧栏、触控和键盘操作。

项目收藏夹只是额外的个人组织维度，不成为官方 DLC 数据或现有个人标记的替代品。

## 模块边界

- `js/project-collections.js`：纯数据模型、验证、创建／重命名／移动／删除、排序、归类和子树查询；浏览器与 Node 测试共用。
- `js/personal-store.js`：版本化本地存储、旧数据迁移、导入验证和导出；封装 `localStorage`。
- `js/project-tree-view.js`：项目树渲染、菜单、拖拽和移动对话框；只通过模型接口修改数据。
- `js/project-picker.js`：单个／批量归类使用的可搜索多选目录树。
- `js/app.js`：把新增模块接入现有筛选、详情和批量模式，不继续堆积目录算法。

## 错误处理

- `localStorage` 解析失败时保留可恢复提示，不用空对象静默覆盖损坏数据。
- `localStorage` 写入失败时回滚内存修改并提示用户导出备份或释放空间。
- 拖拽和移动操作先验证后提交。
- 删除和导入属于高影响本地操作，必须明确确认或先完整验证。
- 对不存在的 DLC App ID 保留关系但在界面中标记为暂不可用，不阻止其他数据使用。

## 测试与验收

### 数据模型

- 无限层级创建、重命名、删除、移动和排序。
- 同级重名拒绝、跨父节点重名允许。
- 循环移动、项目作为子节点等非法结构被拒绝。
- 同一 DLC 多项目／多目录归类与去重。
- 删除目录只移除相关归类关系，不修改个人标记。
- 子树递归汇总和同一 DLC 去重。

### 存储

- 旧 `localStorage` 自动迁移且个人标记完全保留。
- 新旧导出文件导入。
- 无效版本、缺父节点、循环、非法 App ID 和损坏 JSON 均拒绝。
- 导入或写入失败后原数据不变。

### 界面

- 新建项目和无限子目录。
- 展开、折叠、重命名、菜单移动和删除确认。
- 桌面拖拽排序／改变父级，手机菜单等价操作。
- 详情单个多目录勾选。
- 卡片和表格批量选择、批量加入多个目录。
- “包含子目录”开关、递归去重和节点计数。
- 项目目录筛选与搜索、官方分类、价格、个人筛选及排序组合。

### 回归

- 运行全部现有自动化测试。
- 增加项目收藏夹的单元、存储和静态 UI 合约测试。
- 执行 JavaScript 语法检查。
- 在桌面与窄屏浏览器中完成新旧功能冒烟测试。
- 核对导入／导出往返后个人标记、项目树和归类关系完全相等。

## 不在本次范围内

- 登录账号或跨设备云同步。
- 多人协作、共享项目或服务器数据库。
- 自动根据 DLC 类型生成章节或目录。
- 将项目收藏夹数据上传到 GitHub。
- 修改官方 DLC 数据、推荐评分公式或 Steam 同步逻辑。
