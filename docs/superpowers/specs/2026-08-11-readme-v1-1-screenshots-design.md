# README v1.1.0 功能介绍与截图更新设计

## 目标

让 GitHub 仓库首页准确展示当前 v1.1.0 界面与项目收藏夹功能。中文 `README.md` 和英文 `README_EN.md` 同步更新；宣传片区域不处理视频，由用户之后在 GitHub 页面手动拖拽上传。

## 内容范围

- 两份 README 都显示当前版本、项目收藏夹、无限层级子目录、详情多目录归类、批量归类、拖拽／移动、递归筛选和本地备份兼容。
- 保留现有 DLC 浏览、搜索、筛选、推荐度、卡片／表格、双语详情、媒体预览和个人标记介绍。
- 中文和英文使用同一套真实页面截图，各自提供对应语言的标题、正文和替代文本。
- 不修改 DLC 数据、业务逻辑、Steam 链接、媒体资源同步或本地个人数据结构。

## 截图方案

采用“覆盖旧文件名＋新增新功能截图”方案：

- 覆盖 `hero-light.png`：当前浅色主页，左侧项目收藏夹可见。
- 覆盖 `hero-dark.png`：当前暗色主页。
- 覆盖 `filters-sidebar.png`：当前左侧官方筛选与项目收藏夹。
- 覆盖 `search-filter.png`：搜索与推荐度组合结果。
- 覆盖 `table-view.png`：当前表格视图。
- 覆盖 `detail-meta.png`、`detail-score-source.png`、`detail-bilingual.png`、`detail-tags.png`、`detail-personal.png`、`detail-steam-link.png`：当前详情弹窗对应区域。
- 新增 `project-tree.png`：演示项目、章节子目录和归类数量。
- 新增 `project-picker.png`：详情页多目录勾选器。
- 新增 `batch-assign.png`：卡片或表格的批量选择与批量归类入口。

截图使用当前本地页面、统一浏览器尺寸和干净的演示数据。不得包含账号、令牌、私人备注或其他敏感信息。

## 宣传片区域

- 删除中文 README 顶部现有的 `user-attachments` 视频链接。
- 删除英文 README 中旧海报下载链接和旧视频上传提示。
- 两份 README 保留“宣传片／Promo Video”标题及 HTML 注释占位，页面渲染时该区域为空白。
- 不删除本地视频文件，以免扩大本次范围；README 不再引用它们。

## README 结构

- 顶部：项目名称、简介、语言切换、在线体验、源码、版本号。
- 宣传片空白占位。
- v1.1.0 项目收藏夹重点介绍与三张新增功能截图。
- 现有功能一览，使用重新截取的当前界面图片。
- 数据保存与导入导出说明，明确数据仅存浏览器本地，删除目录不删除个人标记。
- 更新记录链接。
